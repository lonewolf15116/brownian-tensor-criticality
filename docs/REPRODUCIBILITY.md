# Reproducibility standard (future work)

For any subsequently approved numerical run record: immutable commit SHA, protocol version, environment (OS, Python and package versions), RNG algorithm and seeds, tensor construction and symmetry convention, Brownian covariance normalization, time-step/grid, eigenpair selection and branch tracking, stopping conditions, convergence checks, output hashes, negative controls and failures.

Do not populate this with invented runs. No numerical execution is authorized at Gate 0.
