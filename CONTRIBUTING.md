# Research contribution protocol

All scientific changes go through a draft PR. Main is the stable record. Do not merge a research-stage change without owner approval.

## Evidence hierarchy
1. Verified theorem/proof with assumptions and source provenance.
2. Independently checked symbolic derivation or reproducible numerical evidence.
3. Exploratory calculations, clearly labelled.
4. Conjectures and ideas, never presented as findings.

## Before scientific work
Record question, hypothesis ID, scope, permitted actions, assumptions, negative controls, stopping rules and decision owner. Keep literature claims traceable to primary sources. Do not claim novelty from keyword absence.

## No automatic authorization
A passing CI check, draft protocol, issue or code commit never authorizes numerical experiments, publication, or changing a gate. Owner approval must specify the bounded work.
